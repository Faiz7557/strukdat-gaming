Pandu kuis bersama

Buka lobi, tunggu peserta, lalu mulai. Kamu menentukan kapan kelas beralih ke soal berikutnya.

Semua peserta mendapat waktu sama. Durasi panjang memberi ruang untuk membaca dan berdiskusi saat pembahasan.

Bagaimana skor, peringkat, dan koneksi bekerja?

Jawaban benar mendapat 800 poin + bonus kecepatan 0–200. Salah atau tidak menjawab: 0. Rumus: 800 + round(200 × (1 − waktu respons / batas waktu)). Maksimum 20.000 poin.

Peringkat diurutkan dari skor tertinggi, jumlah benar terbanyak, lalu total waktu jawaban benar tersingkat. Nilai yang sama berbagi peringkat. Bonus dapat membuat peserta yang lebih cepat mengungguli peserta dengan lebih banyak jawaban benar; akurasi tetap ditampilkan terpisah.

Jawaban pertama dikunci. Tidak ada pengurangan poin atau bonus streak. Waktu dihitung sampai jawaban diterima server, sehingga koneksi memengaruhi bonus. Soal ditutup saat semua menjawab atau timer habis. Kunci baru dibuka saat pembahasan.

Gunakan alamat server yang sama. Untuk perangkat berbeda, host menjalankan npm run start:lan dan membagikan alamat IP komputer, bukan localhost. Sesi dapat dilanjutkan setelah refresh pada tab yang sama. Ruang berlaku 3 jam dan hilang jika server dimulai ulang.
